# 前端设计方案 — Bento Dark UI

> 适用项目：AI智能聊天互动系统
> 前端技术栈：Vue3（Composition API） + Vite + HTML5 + CSS3 + JavaScript
> 设计风格：沉浸式深色 BentoGrid + Glassmorphism
> 架构设计：标准前后端分离，WebSocket 自定义 JSON 协议通信

---

## 一、设计哲学

### 1.1 核心理念

以 **"安静的沉浸感"** 为第一优先级。所有视觉元素服务于对话本身，不做多余装饰。

- **BentoGrid 布局**：信息以不规则网格卡片排布，打破传统聊天应用的"左列表 + 右对话"双栏死板结构，每个功能模块（联系人、对话、AI入口、设置）都是独立的悬浮卡片。
- **Glassmorphism 玻璃拟态**：卡片使用半透明背景 + `backdrop-filter: blur()` + 微弱边框高光，营造"浮在深空之上"的层次感。
- **克制的动效**：所有动画以"微交互"为尺度——气泡入场放大 1.02x、联系人卡片悬停光晕、发送按钮脉冲——没有全屏过渡、没有弹跳、没有干扰注意力的元素。

### 1.2 与项目架构的适配

| 约束 | 设计对策 |
|------|----------|
| Vue3 组合式 API + Vite | 组件以 Vue SFC（Single-File Component）实现，Composition API 组织逻辑，CSS 用 scoped 样式避免冲突 |
| WebSocket 通信 | 前端通过 api/ 目录封装 WebSocket 连接，UI 层与通信层分离，自定义 JSON 协议与后端交互 |
| 页面多（登录/聊天/请求/设置） | 采用 Vue Router 单页面应用路由，views/ 目录管理不同页面视图，组件复用性强 |
| 头像/验证码等静态资源 | 通过后端 `/static/` 路径引用，前端做加载态和 fallback |

## 二、设计系统（Design Tokens）

### 2.1 色彩体系

```
/* ===== 基础色 ===== */
--bg-primary:       #0F0F1A;    /* 深空灰 — 页面主背景 */
--bg-secondary:     #16162A;    /* 卡片/面板背景 */

--glass-bg:         rgba(22, 22, 42, 0.65);   /* 半透明卡片底 */

--accent-gradient:  linear-gradient(135deg, #00F0FF, #B350FF);

--text-primary:     #E8E8F0;    /* 主文字 — 浅灰白 */
```

### 2.4 阴影与光效


```
│  ──────────────── Footer ────────────────                   │

```

#### 设计要点

- **Hero 区域**：标题文字使用渐变色（`--accent-gradient`），背景有极淡的网格线纹理（CSS `background-image: linear-gradient(rgba(255,255,255,0.02) 1px, transparent 1px)`），增加空间感。
- **Bento 网格**：下方 3-4 张卡片采用 `grid-template-columns: 1fr 2fr 1fr` 不等宽排列，卡片为玻璃拟态风格。
  - 左卡片：数据统计（"1000+ 消息"、"实时 AI"）
  - 中卡片：模拟对话预览（自动轮播几条消息气泡）
  - 右卡片：AI 功能入口（紫罗兰强调色边框）
- **顶栏**：`position: fixed`，背景 `backdrop-filter: blur(20px)` + 半透明深色底，导航链接悬停时底部出现霓虹蓝下划线。
- **按钮**：主按钮使用 `--accent-gradient` 背景 + 微弱 glow 效果；次按钮为描边风格。

#### 关键交互

| 元素 | 动效 |
|------|------|
| Hero 标题 | 页面加载时 fade-in + 轻微上移（`translateY(12px) → 0`，600ms） |
| Bento 卡片 | 交错入场（每张延迟 100ms），hover 时 `translateY(-4px)` + 光晕边框 |
| "开始使用" 按钮 | hover 时 glow 扩散，active 时微缩 |
| 对话预览卡片 | 自动轮播消息气泡，每条 fade-in + 放大 1.02x |

#### 注册模式展开

切换到注册 Tab 时，表单区域平滑展开，额外显示：

```
   ┌──────────────────────┐
   │  用户名               │   ← 注册独有
   └──────────────────────┘

   └──────────────────────┘

   [        注  册        ]
```

#### 设计要点

- **居中卡片**：登录表单为页面中心的一张玻璃卡片，`max-width: 420px`，背景 `--glass-bg` + `backdrop-filter: blur(24px)`。
- **输入框**：深色底 `--bg-input`，边框 `rgba(255,255,255,0.08)`，聚焦时边框变为 `--accent-blue` + 微弱 glow。无 placeholder 时用浮动 label。
- **验证码行**：输入框与 SVG 图片并排，图片右侧放刷新按钮（旋转图标，点击时 spin 360°）。
- **Tab 切换**：登录/注册为自定义 Tab，选中态底部有渐变下划线，切换时表单内容 crossfade。
- **底部装饰**：4 张小 Bento 卡片做装饰，展示产品特性关键词（"实时对话"、"AI 助手"、"群聊"、"安全加密"），不占功能空间。
- **密码规则提示**：注册时输入框下方实时显示规则（长度、复杂度），通过/未通过用绿色/红色小圆点指示。

#### 关键交互

| 元素 | 动效 |
|------|------|
| 表单卡片 | 页面加载时 scale(0.95)→1 + fade-in，400ms |
| Tab 切换 | 下划线滑动（`translateX` 动画），表单内容 opacity 过渡 |
| 输入框聚焦 | 边框色渐变 + 微 glow，200ms |
| 验证码刷新 | 图片 fade-out/fade-in + 刷新按钮 spin |
| 登录按钮 | 点击后进入 loading 态（按钮内出现旋转圆环），成功后全屏 fade-out 进入聊天页 |
| 错误提示 | 输入框底部 slide-down 错误文字，红色，3s 后 fade-out |

#### 密码输入框详细设计

```
   ┌──────────────────────────────────────┐
   │  🔒  密码                    [👁 显隐] │
   └──────────────────────────────────────┘
   ● 至少8个字符
   ● 包含大写字母
   ● 包含数字                    ← 实时规则指示器
```

- 显隐按钮：点击切换密码明文/密文，图标 crossfade
- 规则指示器：每条规则前有小圆点，满足时圆点变绿 + 打勾动画

## 五、动效规范

### 5.1 全局原则

- 所有动效时长：`150ms - 400ms`
- 缓动函数：`ease-out` 为主，`ease-in-out` 用于循环动画
- 禁用 `bounce`、`elastic` 等夸张缓动
- 尊重 `prefers-reduced-motion`：用户开启减少动效时，禁用所有非必要动画

```css
@media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
        animation-duration: 0.01ms !important;
        transition-duration: 0.01ms !important;
    }
}
```

### 5.2 核心动效列表

| 动效名称 | 触发场景 | 参数 |
|----------|----------|------|
| `bubble-in` | 新消息出现 | scale(0.98)→1 + opacity, 200ms |
| `card-hover-glow` | 卡片悬停 | box-shadow 扩散 + translateY(-2px), 200ms |
| `tab-slide` | Tab 切换 | translateX 滑动 + 内容 opacity, 250ms |
| `fade-in-up` | 页面/元素入场 | translateY(12px)→0 + opacity, 400ms |
| `pulse-glow` | 发送按钮激活 | box-shadow 呼吸效果, 2s infinite |
| `spin` | 加载/刷新 | rotate(360deg), 800ms linear infinite |
| `typing-dot` | AI 思考中 | 三点依次跳动, 1.4s infinite |
| `shake` | 验证码错误 | translateX ±4px, 300ms |

## 八、设计验收标准

| 维度 | 标准 |
|------|------|
| 视觉一致性 | 所有颜色、间距、圆角、阴影均使用 CSS 变量，无硬编码值 |
| 玻璃效果 | 卡片背景透明度、模糊度、边框高光符合设计稿 |
| 可读性 | 正文对比度 ≥ 4.5:1（WCAG AA），标题 ≥ 3:1 |
| 动效性能 | 所有动画仅操作 `transform` 和 `opacity`，不触发布局重排 |
| 无障碍 | 所有交互元素可键盘操作，焦点态清晰可见 |
| 加载体验 | 首屏 < 2s，骨架屏覆盖所有异步加载区域 |
