# 前端设计方案 — 微信浅色风格

> 适用项目：AI智能聊天互动系统
> 前端技术栈：Vue3（Composition API） + Vite + HTML5 + CSS3 + JavaScript
> 设计风格：微信浅色风格 + BentoGrid 卡片布局
> 架构设计：标准前后端分离，通过 WebSocket 代理与后端 TCP 服务器通信

---

## 一、设计哲学

### 1.1 核心理念

以 **"简洁、熟悉、高效"** 为第一优先级。复刻微信的视觉语言，降低用户学习成本。

- **微信风格**：采用微信经典的绿色主色调、白色卡片、灰色背景，用户无需学习即可上手。
- **BentoGrid 布局**：聊天列表页采用不规则网格卡片排布，将搜索、AI 入口、最近聊天整合在一个页面中。
- **玻璃拟态**：登录页使用 `backdrop-filter: blur()` 实现毛玻璃效果，提升视觉层次。
- **克制的动效**：所有动画以"微交互"为尺度——气泡入场、卡片悬停变色——没有干扰注意力的元素。

### 1.2 与项目架构的适配

| 约束 | 设计对策 |
|------|----------|
| Vue3 组合式 API + Vite | 组件以 Vue SFC 实现，Composition API 组织逻辑，CSS 用 scoped 样式避免冲突 |
| TCP 自定义协议通信 | 前端通过 WebSocket 代理连接后端，api/ 目录封装通信层，UI 层与通信层分离 |
| 页面多（登录/聊天/请求/设置） | 通过 store 状态管理切换页面视图，组件复用性强 |
| 头像/验证码等静态资源 | 通过后端 `/static/` 路径引用，前端做加载态和 fallback |

- **密码强度**：实时显示密码强度指示器和规则检查
- **注册模式**：展开显示 用户名、用户ID、密码、确认密码、手机号（选填）

## 五、动效规范

### 5.1 全局原则

- 所有动效时长：`150ms - 300ms`
- 缓动函数：`ease-out` 为主
- 尊重 `prefers-reduced-motion`

### 5.2 核心动效列表

| 动效名称 | 触发场景 | 参数 |
|----------|----------|------|
| `fadeIn` | 元素入场 | translateY(8px)→0 + opacity, 300ms |
| 悬停变色 | 卡片/按钮 | border-color 渐变, 150ms |
| 发送按钮 | 点击 | background 渐变, 150ms |

## 八、通信协议

### 8.1 传输层

```
浏览器前端 --WebSocket(8081)--> proxy-server.js --TCP(8080)--> C++后端
```

### 8.2 报文格式

与后端 Buffer 类 (sep=1) 一致：

```
┌──────────────┬───────────────────┐
│ 4字节长度头    │ JSON 字符串        │
│ (大端序)      │ (UTF-8)           │
└──────────────┴───────────────────┘
```

### 8.3 消息字段

与后端 `Message` 结构体对齐：

```json
{
  "type": 1,
  "from_user_id": "user001",
  "to_user_id": "user002",
  "content": "消息内容",
  "extra": "{}",
  "timestamp": "1234567890"
}
```

## 九、设计验收标准

| 维度 | 标准 |
|------|------|
| 视觉一致性 | 所有颜色使用 CSS 变量 `--wx-*`，无硬编码值 |
| 微信风格 | 绿色主色调、白色卡片、灰色背景，符合微信视觉语言 |
| 可读性 | 正文对比度 ≥ 4.5:1（WCAG AA） |
| 动效性能 | 所有动画仅操作 `transform` 和 `opacity` |
| 响应式 | 桌面端完整布局，移动端底部导航 |
