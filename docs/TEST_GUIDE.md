# AI智能聊天互动系统 - 联调测试清单

## 前置条件

### 1. 环境准备
- [ ] MySQL 8.0 已安装并启动
- [ ] Redis 已安装并启动（可选）
- [ ] Node.js 16+ 已安装
- [ ] g++ 支持 C++11

### 2. 数据库初始化
```bash
mysql -u root -p < db/mysql/init.sql
```

### 3. 配置文件
- [ ] 检查 `config.ini` 中的数据库配置
- [ ] 检查 `config.ini` 中的 AI API 配置

---

## 启动测试

### 4. 编译后端
```bash
make clean && make
```
- [ ] 编译成功，无错误

### 5. 启动后端
```bash
./ai_chat_server
```
- [ ] 服务启动成功
- [ ] 数据库连接成功
- [ ] ChatService 初始化成功
- [ ] 监听端口 8080

### 6. 启动代理
```bash
node proxy-server.js
```
- [ ] WebSocket 代理启动（端口 8081）
- [ ] 静态文件服务启动（端口 8082）

### 7. 启动前端
```bash
cd frontend && npm install && npm run dev
```
- [ ] Vite 开发服务器启动（端口 5173）

## 常见问题

### Q1: 后端启动失败
- 检查 MySQL 是否启动
- 检查 config.ini 配置
- 检查端口是否被占用

### Q2: WebSocket 连接失败
- 检查代理是否启动
- 检查防火墙设置
- 检查浏览器控制台错误

### Q3: AI 不回复
- 检查 AI API 配置
- 检查网络连接
- 查看后端日志

### Q4: 消息不显示
- 检查数据库连接
- 检查消息是否保存
- 刷新页面重试
